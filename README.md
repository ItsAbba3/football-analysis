# رادار شوت | تحلیل آماری فوتبال اروپا

داشبورد وب فارسی (راست‌به‌چپ) و ابزار خط فرمان پایتون برای تحلیل شوت، شوت در چارچوب، عملکرد مقابل رده‌های جدول، شوت‌پذیری حریف بعدی، برترین‌های ۵ لیگ اروپا و آمار گل و کارت زرد بازی‌های خانگی.

## امکانات وب‌اپلیکیشن (`docs/`)
- **تحلیل بازیکن:** آمار ۱۰ بازی و ۵ بازی رسمی اخیر (مجموع، میانگین، میانه، SoT%)، تفکیک مقابل یک‌سوم بالایی، میانی و پایینی جدول، مقایسه دو بازیکن روی نمودار راداری، و **کارت شوت‌پذیری حریف بعدی** (میانگین و میانه شوت و SoT خورده حریف بعدی).
- **تحلیل باشگاه:** آمار شوت و SoT باشگاه مقابل یک‌سوم جدول (زده در برابر خورده)، نمودار راداری ساختار هجومی/دفاعی، شوت‌پذیری حریف بعدی، و ۱۰ بازیکن برتر باشگاه.
- **برترین‌های لیگ:** ۱۰ بازیکن برتر هر لیگ در ۵ و ۱۰ بازی اخیر لیگ + نمودار پراکندگی حجم شوت در برابر دقت.
- **بازی‌های خانگی (گل و کارت زرد):** میانگین گل زده، گل خورده، کل گل بازی و کارت زرد میزبان و مهمان در ۵ لیگ معتبر اروپا.
- **به‌روزرسانی خودکار روزانه:** از طریق GitHub Actions (`.github/workflows/daily-update.yml`) هر روز ساعت ۰۴:۰۰ UTC به‌روزرسانی می‌شود، به علاوه دکمه به‌روزرسانی زنده مستقیم از ESPN در مرورگر.

## فعال‌سازی روی GitHub Pages
1. وارد تنظیمات ریپو در GitHub شوید: `Settings -> Pages`
2. در بخش **Build and deployment** گزینه `Deploy from a branch` را انتخاب کنید.
3. شاخه `main` و پوشه `/docs` را انتخاب کرده و Save بزنید.
4. برای فعال شدن آپدیت خودکار روزانه، در تب **Actions** مطمئن شوید workflow فعال است (`Daily Football Stats Update`).

## اجرای محلی (CLI پایتون)
```bash
# تحلیل بازیکن
python football_analyzer.py player "Lamine Yamal" "Julian Alvarez"

# تحلیل باشگاه
python football_analyzer.py team "Barcelona" "Atletico" "Osasuna" "Real Sociedad"

# ۱۰ بازیکن برتر لیگ
python football_analyzer.py league laliga

# ساخت مجدد فایل‌های JSON سایت
python build_site_data.py --season 2026
```
